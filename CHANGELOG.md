## [0.1.0] - 2026-11-23

First public release.

- WordPress plugin: one JSON price store rendered everywhere via `[po_price]`, `[po_peroz]`, `[po_perunit]`, `[po_permonth]`
- Checked-date stamp rendered with every price
- Agent Skill (`skill/SKILL.md`) and `AGENTS.md` included
